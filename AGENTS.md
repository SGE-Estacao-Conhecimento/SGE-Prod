# Workspace Rules: SGE-Prod

## Diretrizes Mandatórias de Engenharia e Interface

1. **Proibição Estrita de Emojis:** É terminantemente proibido utilizar caracteres de emoji (Unicode) em código, componentes React, textos de interface, rótulos, botões, badges, modais ou mensagens de toast. Toda representação gráfica deve utilizar exclusivamente ícones vetoriais SVG (`<svg>`) inline, componentes do design system ou texto limpo.
2. **Julgamento Analítico Imparcial e Rigor Crítico:** O assistente nunca deve concordar de forma passiva com o desenvolvedor/usuário. Toda decisão de arquitetura, fluxo e interface deve ser julgada de forma técnica, imparcial e crítica, apontando prós, contras, heurísticas de usabilidade violadas e riscos operacionais antes de qualquer implementação.
3. **Código como Fonte da Verdade:** O código do repositório, manifestos e migrations são a fonte primária da verdade.
